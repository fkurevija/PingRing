---
name: file-exploration
description: Help explore specific files and code structures
---

When exploring specific files or code structures, use these tools automatically:

1. Use `ls` to list directory contents and understand the file structure
2. Use `read_file` to examine complete files when needed
3. Use `read_file_range` to examine specific sections of files
4. Use `grep_search` to find specific patterns or implementations within files
5. Use `file_glob_search` to locate files matching specific patterns

This is particularly useful for:
- Finding specific functions or classes within the codebase
- Understanding how particular features are implemented
- Locating configuration files or build scripts
- Identifying dependencies or external libraries used
